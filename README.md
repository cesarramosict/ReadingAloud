# ReadingAloud

An open-source Android app that reads your books, articles, and
documents aloud in the language you choose, with the voice you prefer.

## Why

Sometimes you have books and articles you want to read, but no time to
sit down and read them. ReadingAloud turns any text into audio, so you
can listen while doing other things.

## Status

Early development. Building it step by step as a learning project.

## Planned features

- Import text files (.txt)
- Read text aloud using the device's text-to-speech
- Support multiple languages
- Choose a male or female voice
- Later: EPUB, PDF, and web articles

## Tech

- Language: Java
- Platform: Android
